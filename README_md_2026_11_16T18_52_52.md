
# Freddy Wootton — Personal Portfolio Site

A clean, accessible, static portfolio site built with HTML, CSS, and vanilla
JavaScript. Hosted on GitHub Pages.

---

## Quick Start

### Option A: GitHub Desktop (no command line)

1. Download [GitHub Desktop](https://desktop.github.com/).
2. Sign in with your GitHub account.
3. Click **File > New Repository**.
   - Name: `YOUR_USERNAME.github.io` (this exact name enables GitHub Pages).
   - Choose a local folder (e.g. your Desktop).
   - Tick "Initialize with a README" — we'll replace it.
4. Open the folder on your computer. Copy all the site files into it
   (replacing the auto-generated README).
5. Back in GitHub Desktop, you'll see all the files listed as changes.
   - Write a commit message, e.g. "Initial site files".
   - Click **Commit to main**.
   - Click **Push origin** (top bar).
6. Done! Visit `https://YOUR_USERNAME.github.io` after a minute or two.

### Option B: Command Line (Git)

```bash
# 1. Create the repo on GitHub first (name it YOUR_USERNAME.github.io)
# 2. Clone it locally
git clone https://github.com/YOUR_USERNAME/YOUR_USERNAME.github.io.git
cd YOUR_USERNAME.github.io

# 3. Copy all site files into this folder, then:
git add .
git commit -m "Initial site files"
git push origin main
